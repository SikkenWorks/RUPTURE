- Firmware package: **610,086 bytes**, SHA-256 `be142fdd22bbb83ded4c663e6ebcea0318fc186bcdbf99c6303e362943718e43`.

- Audio DSP and per-sample effects source unchanged in this iteration.

## New V1.28 tests (host, not real FM1)

- **Project storage:** PASS, duplicate to free slot, rename, delete, crash-safe catalog CRC/commit, reject dangerous operations, flash erase boundary checks.
- **Legacy storage WIPE ALL:** PASS, both explicit confirmation tokens required; erase and read-back only in `0x97000..0xDFFFF`. Boot, application, update loader and OTA staging are not erased. Previously deleted data cannot be recovered with this operation.
- **Global preferences:** PASS, default-on screensaver / default-off AUTO SAVE, backward compatibility of existing global volume/autosave records, retention across NOR compaction and project transfers.
- **Sequence slots:** PASS, packed sequence copying in either slot direction and removal without damaging unrelated slots.
- **Native UI:** PASS, card layout, 12-project browse, nested sequence manager, explicit YES/NO WIPE ALL, ABOUT wrapped text/scroll, header E middle stroke, USB power icon on/off and 1-bit screensaver frames.
- **Native display exports:** 52 screenshots regenerated by the actual native C renderer; all 240×240 pixels.
- **WebInstaller/site parity:** PASS, embedded FWSC payload byte-for-byte equals standalone .fwsc. Both scripts validate exact SHA-256, length and product identity.

## Earlier regressions

- The existing CXS, MIDI, filter, effects, subs, 12-project/8-sequence schema, FX memory and audio-stability regressions passed in the full historical suite up through V1.27.
- Prior V1.25/V1.26 source-contract regressions were updated to recognize the additional V1.28 storage manager name-editor branch. Their preserved SAVE-only behavior passed.
- Native V1.28 storage, native UI and sequence tests also passed independently.

## Not established in this environment

- I cannot physically run the firmware on a connected FM1 here. The author regularly tests RUPTURE on real FM1 units; this new binary needs targeted checks of USB unplug, button routing, flash erase boundaries, the name editor and end-to-end project/sequence actions on the actual device.
- A safe recovery route and a verified backup are strongly recommended before experimenting with a full storage wipe.
- Wipe erases *recognized* legacy FM1 user-storage sectors, not arbitrary unidentified data in undocumented flash areas. It must never erase boot, application or OTA sectors.
- The protected OTA loader is retained. Progress during the actual separate loader write is not drawn on the FM1 by this revision; WebInstaller reports real USB transfer progress.
