# RUPTURE V2.0.14: FM1 hardware checklist

1. Make a complete backup and verify recovery before flashing.
2. In SETTINGS > PRESETS KNOB > GROWL PERFORMANCE select EXPRESSION LATCH.
3. Play a long note with BRIGHT and BODY set to zero. Turn EXPRESSION to 0.
   Verify that the bass remains audible and does not become silent.
4. Confirm LATCH holds its value while the knob is stationary.
5. Select EXPRESSION RETURN. Move PRESETS toward either extreme, then stop.
   The sound must glide back to its neutral EXPRESSION=50 character.
6. Verify an explicit PLAY LEVEL=0 still mutes the oscillator.
7. Reboot: GROWL remembers the mode; CXS remembers its separate assignment.
8. Stress sustained notes with SUB1, SUB2, Channel EQ low values and HALL.
   Check clicks, distortion and the DMA LATE counter on physical hardware.
9. Check other presets, project save/reload, MIDI and OTA before release.

Host PCM tests are not a substitute for physical DMA timing tests.
