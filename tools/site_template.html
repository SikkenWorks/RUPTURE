BEFORE YOU START

Installation guide

  1. Back up your work. Existing PJT33 projects are not backward-readable by RUPTURE V1.16 or older.
  2. Use Chrome or Edge. Open this page on GitHub Pages (HTTPS), or on localhost.
  3. Connect the FM1. Use a reliable USB cable and click CONNECT FM1.
  4. Approve the update. Select the FM1 MIDI ports if necessary, tick the backup confirmation, and start the installer.
  5. Watch the device. Keep USB connected until the loader completes. Verify the new V{{VERSION}} version on the FM1 screen.
Recovery first. OCT− ROM recovery and REC Safe Mode remain unchanged by this firmware. The protected 16 KiB bootheader and trusted OTA loader are left intact. Do not repeatedly retry after an unverified loader handoff.
