NEW BOOT ANIMATION (V1.20)

A jagged black-and-white tear opens across the 240×240 panel and reveals SIKKENWORKS / Born out of passion. This is application startup artwork, not a replacement for the protected ROM recovery or OTA loader screens. The animation runs before normal audio startup and does not add DMA/FX load.

SELECT: GLOBAL SCREEN LIST

On any regular screen where SELECT is not otherwise assigned, turn SELECT to open the same screen list as PLAY. If SELECT already chooses a SEQ step, FX entry, settings row, project slot, name position or HELP card, that behavior is preserved. The shortcut never interrupts OTA, recovery or the first-run wizard.

PLAY & HOME

ALGORITHM switches CXS ↔ SAWTOOTH. The selected oscillator name appears between PLAY and OCT. CXS: K1 PRESSURE · K2 BALANCE · K3 MEMORY · K4 DENSITY. SAW: K1 BRIGHT · K2 EDGE · K3 BODY · K4 LEVEL; these shape the real SAW audio. The saved macro values are shared between modes. Short HOME cycles PLAY → SHAPE → SUB 1 → SUB 2 → PLAY. Long HOME returns to PLAY from any screen.

SHAPE

K1 WEIGHT · K2 EDGE · K3 BITE · K4 PUNCH. In SAW mode all four now shape sustained tone: WEIGHT adds low body, EDGE adds colour, BITE adds harmonic bite and PUNCH accents every saw edge (not just the first eight cycles). ALGORITHM also switches the main CXS/SAW oscillator. These parameters are per-preset and persist when you SAVE.

V1.24: SUB + FX HEADROOM

Turn on SUB 1 and/or SUB 2 with TYPE = CXS or CLASSIC, then adjust ALGORITHM BLEND (0–100). CLASSIC bypasses the CXS filter cutoff but still follows note envelope, velocity and FX. The blend is slewed to prevent gain clicks and the pre-FX mix has additional peak safety. All eight FX can be used together; actual DMA and distortion must still be checked on hardware. K1–K4 have been lowered visually to clear the title panel; the header RUPTURE logo contains a white-on-black fracture.

SUB 1 & SUB 2

K1 TYPE (OFF/CXS/CLASSIC/SQUARE/SAW) · K2 OCTAVE (−2/−1/0/+1) · K3 DETUNE (−50 to +50 cents) · K4 DRIFT (0–100) · ALGORITHM BLEND (0–100, fifth center knob). BLEND is saved per project, other SUB controls per preset. CLASSIC is band-limited square-like; OFF preserves original CXS audio. Both sets persist per saved preset.

NOTE MEMORY

Six-note monophonic memory: K1 LAST/HIGH/LOW · K2 LEGATO ON/OFF · K3 GLIDE 0–400 ms · K4 BEND 0–12 semitones. SAVE stores these with the active project/preset; older snapshots restore defaults.

SEQUENCER

SEQ opens step editor. SELECT moves the step cursor including STEP 1. With transport stopped, press SEL to CLEAR the entire selected step (all notes, local HOLDs and parameter locks); HOLD links from that step to later steps are also removed, but other steps remain. Tapping an existing piano key still removes only that note. During REC, keys overdub instead of erasing. Hits quantize to the NEAREST step using key-contact timing and swing; the very first key after the two-bar countdown records on step 1 even across a delayed display refresh. Hold a key across steps to record sustain; Note OFF finishes its note length without cutting longer existing overdubs. The visual REC playhead follows the audio-clock step, with the existing audio-first LCD protection. SELECT scrolls steps; press a piano key to toggle a step note. K1 length 4/8/16/32/64/128 (4/8 hide extra boxes) · K2 BPM · K3 selected-step VELOCITY · K4 GATE. REC records at the audio playhead with an independent quarter-note metronome following BPM; PRESETS adjusts BPM at all times, including live REC. Only during live REC, ALGORITHM changes metronome volume 0–100; once REC stops ALGORITHM returns to note HOLD length editing. The click is silent in normal playback and never steals the monophonic synth voice. PLAY/STOP controls playback. White-key LEDs show the current step. Half-bright LEDs now use faster 455 Hz PWM (DIM LO 303 Hz) to avoid the old visible flicker. Long SEQ no longer opens the library. Hold SEQ + turn PRESETS left/right to rotate the ENTIRE pattern one step per detent (wrap, no dropped steps), including sustain, explicit HOLD links and locks. SAVE on the sequencer opens the 8 named sequence slots.

ARP, SCALE GUIDE & KEYLOCK

ARP K1 mode OFF/UP/DOWN/UPDOWN/ORDER/RANDOM/CUSTOM/RIFF, K2 RATE, K3 OCTAVES, K4 GATE. Scale controls display named notes/scales rather than numbers.

FILTER / FX / LFO / EQ

FILTER includes a 24 dB/oct resonant ladder-style filter. FX SELECT scrolls REVERB (Spring/Hall/Room), DELAY, CHORUS, MOSFET, COMPRESSOR, TILT EQ, OCTAVE FUZZ and SANDPAPER; SEL toggles effect; K1–K4 control the selected effect. EDIT opens Channel EQ 2.0: LOW shelf, BODY bell, BITE bell, AIR shelf (each ±9 dB). Press EDIT again to cycle GAIN / FREQ / PEAK WIDTH (Q) pages; SEL does not switch EQ pages. K1–K4 adjust each band gain/frequency; on Q, K2 changes BODY width and K3 changes BITE width (0.3 broad to 8 narrow). ALGORITHM switches EQ2/LEGACY. New projects keep the EQ fully bypassed by default; EQ2 is available when enabled; older saved projects preserve their historical legacy sound. LFO PITCH and LEVEL modulate CXS directly.

RUPTURE FX (V1.22)

Eight FX: REVERB, DELAY, CHORUS, MOSFET, COMPRESSOR, TILT EQ, OCTAVE FUZZ, SANDPAPER. WAVEFOLDER and TRANSIENT SHAPER have been removed. COMPRESSOR: K1 Threshold, K2 Ratio, K3 Attack, K4 Release. TILT EQ: K1 Tilt, K2 Freq, K3 Mix, K4 Output. OCTAVE FUZZ: K1 Drive, K2 Octave Up, K3 Tone, K4 Mix, with automatic wet loudness matching. SANDPAPER: K1 Smooth, K2 Soft, K3 Warmth, K4 Mix. FX values and bypass save per project.

SANDPAPER

K1 SMOOTH, K2 SOFT, K3 WARMTH, K4 MIX. Smooths gritty CXS highs and rounds peaks while preserving bass weight. Settings save with each named project after SAVE or guarded autosave.

GLOBAL, HELP & PANIC

GLO uses SELECT+SEL cards. STORAGE → PROJECTS refreshes its saved-project catalog automatically; the normal project menu need not be opened first. SETTINGS → MASTER VOLUME (0–200%, K1 edits as soon as highlighted; SEL opens the detail page) or AUTO SAVE (OFF by default; highlight with SELECT and toggle directly using SEL without another screen). Both settings persist device-wide. GLO → HELP is the onboard guide. GLO → AUDIO DIAGNOSTICS is the read-only realtime DMA diagnostic panel; HOME is back. Hold GLO for PANIC.

SAW BASS (V1.77)

SAW BRIGHT now gives more usable warm, lower-harmonic sound through the middle of its range. For a round bass voice, use BRIGHT 35–60, EDGE about 50, WEIGHT modest, BITE/PUNCH low, then shape with the resonant ladder filter and ADSR. Raise BRIGHT/EDGE/BITE for aggressive grit. No second oscillator or audio-rate filter was added.

THREE REVERB ENGINES (V1.78)

FX → REVERB: K1 selects one of three independent algorithms, NOT different parameter presets: SPRING is a dispersive metallic feedback/allpass design; HALL uses an allpass diffuser and long low-pass late tail; ROOM uses discrete early reflections plus a short comb tail. K2 DECAY, K3 SIZE, K4 MIX are independent and stay at your settings on a type change. MIX 0 is dry only, MIX 100 wet only. Only one global engine runs, using the same fixed SRAM tank and no new synth voices or buffers. Engine choice is stored in projects/presets. Older projects default to HALL; older firmware may not accept newly saved SPRING/ROOM projects.

V1.48 SAW HARMONIC GUARD

At high SAW BRIGHT, EDGE, BITE or PUNCH, the harmonic guard blends existing bandlimited SAW tables before saturation to reduce the high-pitched alias whistle without adding synth voices, buffers or tables. Neutral SAW is sample-identical to V1.47. This does not disable the normal effects or change the SUB oscillator wavetable path.

NAVIGATION & STORAGE

SELECT scrolls lists/steps; ALGORITHM operates only where explicitly labeled; SEL confirms; HOME goes back; HOLD HOME returns to PLAY. SAVE from every normal screen, including FX, FILTER, EQ, GLO and SETTINGS, opens the same 12 named projects. In SEQ and SEQ SLOTS, SAVE retains the 8 named sequences. In the NAME editor, SAVE confirms the name. SAVE never overwrites a project until you explicitly confirm an action. Auto Save is OFF by default. Enable it in GLO → SETTINGS. It then follows an intentional SAVE/LOAD and writes only when playback and notes are inactive.

V1.84 HARDWARE INTEGRATION

Only the active hardware section stays fully lit: HOME for PLAY/SHAPE/SUB, FX for all effect pages, EDIT for channel EQ, ENV, LFO, ARP, SEQ and GLO for utility pages. Inactive buttons retain a steady-looking fast dim glow. Pressed buttons take priority; PLAY indicates the running sequencer, REC indicates armed/live recording, and SEQ pulses during the two-bar count-in. K1-K4 acceleration resets on page changes and FX category switches, so the new page starts with one unit per detent. Audio, reverb, MIDI, projects and OTA behavior are unchanged. Physical FM1 validation is still required.

V1.83 MONO HEADROOM

The mono audio mixer no longer runs an unnecessary polyphonic headroom calculation and variable divide for each audio sample. Master gain remains sample-smoothed, and ROOM/HALL/SPRING, CXS/SAW and both SUBs are unchanged. This is a sample-exact host-tested CPU optimization, NOT proof of zero DMA LATE or GUARD on a physical FM1. Check GLO / AUDIO DIAGNOSTICS with fast MIDI, dual SUBs and effects; compare the increment of the counters, not their already accumulated totals.

V1.81 RAPID NOTES / AUDIO HEADROOM

Rapid-note mono pitch and gate processing now avoids idle eight-voice work. Dense note playing coalesces only decorative LCD updates (75 ms; 100 ms at audio pressure), not notes, samples, MIDI or parameters. The three ROOM/HALL/SPRING reverb engines are identical to V1.80. For a hardware check, restart, open GLO → AUDIO DIAGNOSTICS, record DMA LATE/GUARD, play very fast notes with both SUBs and full FX; both counters must remain unchanged. Host tests do NOT certify zero FM1 hardware underruns.

V1.80 REVERB ENGINES & HEADROOM

FX → REVERB: K1 selects SPRING / HALL / ROOM. K2 = DECAY, K3 = SIZE (actual delay geometry), K4 = MIX (100% wet). ROOM now uses a four-delay feedback network with damped early and late reflections; SPRING uses two coupled delay lines and cascaded dispersive allpasses, with dispersion inside the feedback loop. HALL keeps its existing sound. The upgraded ROOM/SPRING use the original 4,096-sample reverb RAM, and the rest of the synthesizer is intact. Phaser, auto-wah, tape, tremolo and decimator Q15 products are optimized exactly. For live safety, open GLO → AUDIO DIAGNOSTICS: DMA LATE and GUARD should not increase during maximum FX + both SUBs. Host tests do not guarantee FM1 hardware headroom; keep backups and recovery ready.

V1.79 AUDIO HEADROOM / SUB DRIFT

Dual SUB detune and DRIFT now use a sample-exact lower-cost oscillator pitch calculation. ROOM, HALL and SPRING, plus the global FX mixer, retain the same audible PCM signal while avoiding repeated 64-bit calculations on normal Q15 samples. Rapidly turning a knob under recent DMA pressure may make LCD redraws slightly less frequent, but audio parameter changes are not delayed. Under GLO > AUDIO DIAGNOSTICS, DSP MAX is a peak since boot; DMA LATE and GUARD are cumulative underrun/safety counters. Power-cycle safely and watch whether they rise during an all-FX SUB+DRIFT stress patch. This test release requires physical validation before live/studio stability can be claimed.

AUDIO DIAGNOSTICS (V1.19)

GLO → SELECT AUDIO DIAGNOSTICS → SEL. WALL MAX and DSP MAX are peak percentages of the DMA deadline. RENDER includes CXS, subs and eight FX; PUBLISH is PCM + USB audio + optional scope. MIN SLACK must remain comfortably above zero. LATE and GUARD should stay at 0. SCOPE SKIP only means waveform graphics were deferred to prioritize the audio engine. This is a software safety improvement, not proof against hardware DMA overruns.

MIDI & USB

USB MIDI IN/OUT and TRS MIDI IN use the native drivers. The WebInstaller progress bar covers OTA transmission; the separate protected OTA loader screen remains unchanged. Back up projects before firmware updates.

V1.23: SAVE A PROJECT

On any HOME page press SAVE. In PROJECTS use SELECT for the desired slot and SEL opens an occupied slot; SAVE stores it (confirmation for other slots). On empty slots edit the 12-character name (SELECT cursor, ALGORITHM character) and press SAVE to commit; SEL does nothing in the name editor. Overwriting occupied slots requires another confirmation. Always check SAVED or SAVE FAILED on the library screen.

V1.75: TWO-BAR RECORD COUNT-IN

REC does not start the sequencer. If it is already playing, REC records immediately as before. When stopped, press REC first to ARM, then PLAY to count in two full bars (eight BPM quarter-note clicks). The sequencer grid and SEQ LED pulse on the beat. After the eighth beat, recording and sequencer playback begin together at step 1; the first played key is captured even at that exact transition. During count-in the synth remains playable but notes are not captured. PLAY or REC cancels count-in. PRESETS always changes BPM; ALGORITHM adjusts metronome volume while armed/recording. No additional synth voices, no changes to persistent projects, and no changes to the trusted OTA loader.

V1.23: SAVE A SEQUENCE

From SEQ press SAVE. Choose one of eight slots using SELECT, SEL opens an occupied slot; SAVE stores it (confirmation for other slots). For a new slot name it and press SAVE; SEL does nothing in the name editor. This writes the sequence into the current saved project. Look for SAVED or SAVE FAILED.

V1.23: EXTEND NOTE SUSTAIN

On SEQ, while NOT in live REC, select a step containing a note. Turn ALGORITHM clockwise to extend the note over following EMPTY steps. During live REC, ALGORITHM adjusts metronome volume instead. Sustain stops BEFORE the next note attack or at the end of the sequence. Counterclockwise shortens it. No extra note attacks are created. Use K3 to change step velocity independently.

V1.23: HELP INFO CARDS

GLO > HELP. SELECT changes between 13 topic cards (including LIVE REC CLICK and SEQ SHIFT). ALGORITHM scrolls within each card. HOME returns. SAVE is only enabled in the project/sequence/name screens.

V1.26: PROJECT & SEQUENCE SLOT CONTROLS

SELECT picks a slot. Empty: SEL or SAVE opens NAME input, SELECT moves cursor, ALGORITHM edits character, SAVE stores. Used: SEL then SEL confirms OPEN; SAVE stores current slot immediately, or SAVE then SAVE confirms overwriting a different active slot. SEL+SAVE together renames an occupied slot. The full-battery icon now fills completely when the measured voltage reaches the full threshold. During firmware update the WebInstaller shows real USB transfer progress; the separate OTA loader controls the FM1 display during physical writing.

SCREENSAVER

After the selected inactivity time (default 30 seconds), Utrecht and the Domtoren appear, and the street gradually fractures into a ravine. Any input returns to the normal display. This does not change the audio engine.

GLO / STORAGE

GLO > SETTINGS > STORAGE > PROJECTS: SELECT highlights a project, SEL opens its actions. OPEN, SEQUENCES, DUPLICATE, RENAME, DELETE. Each project has eight sequence slots with the same actions. Editing another project's sequences requires opening that project first. Duplicating uses a free slot. WIPE ALL requires selecting YES and confirming with SEL; all user projects and recognized legacy storage are irreversibly erased, not firmware/OTA.

OTHER / SCREENSAVER

GLO > SETTINGS > OTHER > SCREENSAVER opens the options menu. SELECT chooses ENABLED or START AFTER; SEL toggles ON/OFF (ON by default); K1 changes the selected delay to 15/30/45/60/90/120/180/300 seconds (default 30). The original monochrome Utrecht skyline splits into a ravine; on the last frame it pauses for 2.2 seconds, reverses all the way to the start and repeats. No extra audio DSP. The REC LED lights only while live sequencer recording is armed.

GLO / ABOUT

GLO > REPORT A BUG opens a sharp QR code for the official RUPTURE GitHub issue tracker. GLO > ABOUT opens the complete origin story of RUPTURE. Turn SELECT to scroll through the paragraphs. HOME leaves the page.

AUTO LOAD PROJECT

GLO > SETTINGS > AUTO LOAD PROJECT. NEW is the default and means the FM1 boots into a fresh unsaved RAM project. SELECT browses NEW and available saved projects only; SEL confirms the target. The preference is remembered in the device-global flash journal. If the chosen project is deleted, startup defaults back to NEW. AUTO LOAD is separate from AUTO SAVE, which stays OFF by default.

STORAGE DELETE / WIPE ALL

STORAGE > PROJECTS > DELETE can now remove the last project (with confirmation); current editing then starts a fresh unsaved project. A project holding shared waveform data for other projects remains protected with a SHARED WAVES warning. WIPE ALL deletes project data and known legacy firmware user storage after a YES confirmation, without erasing boot, application or OTA areas. Save a backup first.

CRT / VCR LOOK

SETTINGS → CRT / VCR LOOK. Use SELECT to highlight, SEL to toggle. Defaults OFF. Save is device-global. OFF restores original pixel-perfect display. The QR code page stays undistorted.

PROJECT SAFETY / KNOB UNDO

An asterisk (*) in the screen header or beside the ACTIVE project signals unsaved changes. SAVE commits only when confirmed by storage. Reopening a project with unsaved work asks for a deliberate second SEL press; HOME cancels. Both PROJECTS and STORAGE use this safeguard. Hold HOME and tap SEL promptly to undo the latest single knob gesture on PLAY, SHAPE, SUB 1/2, TILT, FUZZ or SANDPAPER. Composite FX and sequencer edits cannot be undone.

ENV / LFO HOLD ANIMATIONS

On ENV, holding a note breaks the wall, then a short cloud of dust gradually sinks and clears across eight monochrome frames. The settled wall keeps its subtle shake while the note is held, with no returning smoke, until Note OFF. The original closing animation then runs. On LFO, holding a note opens the sinkhole and makes small pieces of dirt continually fall inside it in an eight-frame loop, with the existing subtle shake. Releasing the note reverses the original sinkhole opening. PLAY water and SOUND SHAPE volcano animations are unchanged. Visual effects run outside the audio path.

FIRST-RUN QUICK TUTORIAL

After setup, RUPTURE asks VIEW QUICK TUTORIAL? SELECT chooses YES or NO, SEL confirms. YES presents 43 read-only native FM1 pages including the main synth, ENV/LFO, every FX, sequencer, library and SYSTEM INFO. The overlay describes how to open each screen and the meaning of K1 to K4 wherever they are functional. SEL advances; SELECT moves backward or forward; ALGORITHM hides and reveals the overlay to inspect the complete screen; HOME exits. NO goes straight to RUPTURE. Existing devices can reopen it from GLO > QUICK TOUR. The walkthrough never changes parameters, saves projects or initializes storage.

V1.25: SAVE, PROGRESS AND USB IDENTITY

In the NAME editor: SELECT moves cursor, ALGORITHM edits text, SAVE writes the current project or sequence; SEL deliberately does nothing. Real project/sequence progress appears on the FM1 LCD for RAM/flash save/load phases, with ERASE / WRITE / VERIFY / READ indicators. A fully RAM-only sequence load finishes almost immediately. USB product now displays RUPTURE by SIKKENWORKS; OTA identity remains FM-1_968. Channel EQ K4 HIGH AIR goes -100 to +100, with 0 neutral and down/up cutting/boosting highs. The trusted separate OTA loader does not display a RUPTURE progressbar; WebInstaller displays actual transfer progress.

V1.85.1: Sequencer LENGTH=4 fix

SEQ K1 LENGTH now limits actual audio playback to the selected number of steps. At LENGTH=4, only steps 1 through 4 can trigger, even when changing LENGTH while playback is running. The other recorded steps are not erased and play again if LENGTH is raised. No other functions were changed.

V1.85: Realtime MIDI diagnostics

Open GLO → AUDIO DIAGNOSTICS. Press SEL to switch between the original DMA metrics and CONTROL MAX, NESTED MAX, SLACK LAST, MIDI BATCH, MIDI QUEUE, MIDI DEFER, GUARD and POST LATE. Watch whether LATE or GUARD increases during fast notes and FX. Normal MIDI response stays immediate; only exceptional bursts above 32 queued events per audio block carry over into the next block.
